# Mentor Feedback Log

*Structured feedback collection using Radical Candor principles: Care Personally + Challenge Directly*

## How to Use This Document

**For Mentees**: Request feedback at regular intervals (monthly recommended). Don't wait for your mentor to offer it—ask specifically for it.

**For Mentors**: Use the framework below to provide balanced, actionable feedback. Remember: Ruinous Empathy (caring without challenging) helps no one.
