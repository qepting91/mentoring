# Action Items & ROE Tracker

*Track commitments and demonstrate Return on Energy (ROE) to your mentor.*

---

## The ROE Principle

From *One Minute Mentoring*: The best way to honor your mentor's time is to **report back on how you applied their guidance**. This isn't just about task completion - it's about showing what you learned.

---

## Action Item Lifecycle

Every action item follows this path:

```
Created → In Progress → Completed → Verified → ROE Captured → Archived
```

| Stage | Who Owns It | What Happens |
|-------|-------------|--------------|
| Created | Meeting notes | Item added with clear success criteria |
| In Progress | Mentee/Mentor | Active work happening |
| Completed | Owner | Work done, ready for review |
| Verified | Other party | Confirmed complete and effective |
| ROE Captured | Mentee | Learning documented |
| Archived | Both | Moved to completed section |

## Rollover Process

At each meeting, review open items:

| Item | Status Check | Action |
|------|--------------|--------|
| | Still relevant? | Keep / Modify / Remove |
| | Still right priority? | Keep / Reprioritize |
| | Still right owner? | Keep / Reassign |
| | Still right timeline? | Keep / Extend / Accelerate |

### Rollover Questions

For each item rolling to next period:

1. Why isn't this done?
2. Is it still important?
3. What needs to change for it to get done?
4. Should we break it into smaller pieces?
